# Proprietary vendor blobs for Snapdragon 750G (SM7225) devices

Proprietary binaries and firmware for Qualcomm SM7225 (Snapdragon 750G)
based devices, extracted from Samsung stock firmware. Consumed by
`android_device_samsung_sm7225-common` during the LineageOS build.
